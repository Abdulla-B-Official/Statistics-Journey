#  Statistics-Journey

A collection of **statistical concepts, hypothesis testing techniques, and practical implementations** documenting my learning journey in statistical analysis using Python.

This repository focuses on understanding and applying statistical methods for data analysis, decision-making, and inference through hands-on examples and real-world problem scenarios.

##  Topics Covered

### Hypothesis Testing

* Null & Alternative Hypothesis
* P-Value Interpretation
* One-Tailed & Two-Tailed Tests
* Statistical Decision Making

### T-Tests

* One-Sample T-Test
* Two-Sample T-Test

### Z-Tests

* One-Proportion Z-Test
* Two-Proportion Z-Test

### ANOVA

* One-Way ANOVA
* Comparing Multiple Groups

### Chi-Square Test

* Test of Independence
* Categorical Data Analysis

##  Repository Goal

The purpose of this repository is to strengthen statistical reasoning and analytical skills through practical implementation of hypothesis testing and statistical inference techniques.

##  Tools & Technologies

* Python
* Jupyter Notebook
* NumPy
* SciPy
* Statsmodels

This repository will continue to grow as I explore additional statistical concepts and analytical techniques.
